# Image replacement guide

Drop your final images into this folder using these exact filenames:

- `profile.webp` — portrait, recommended 1200 × 1500 px (4:5)
- `check-pd.webp` — project cover, recommended 1600 × 1000 px
- `gen-h.webp` — project cover, recommended 1600 × 1000 px
- `nashgui.webp` — project cover, recommended 1600 × 1000 px

WebP is recommended for smaller downloads. Keep each project cover under 500 KB when possible.
